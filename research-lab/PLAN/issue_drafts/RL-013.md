**Status:** Ready for evidence preparation. **Labels:** `ready`, `decision`, `help wanted`. **Milestone:** P1 Resolve open decisions.

## Goal
Select the latest stable engine runtime actually verified as compatible with Lab needs. Do not choose only by version number.

## Deliverables and acceptance
Create `research-lab/PLAN/decisions/D-ENG-LANG.md` comparing supported candidates with dated official release/support evidence, package version requirements, platform wheel/build evidence, licensing, database-driver/harness needs and baseline constraints.
