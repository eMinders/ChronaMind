## Objective
Implement `research-lab/scripts/check_independence.py` to enforce the rules in [`INDEPENDENCE_BOUNDARY.md`](../INDEPENDENCE_BOUNDARY.md) §3 as a mechanical check.

## Scope
The script must:

1. Recursively scan `research-lab/**/*.py` for `import` statements and `from … import …` statements. Flag any that reference the main-app imports in boundary §3 rule 1 (`app`, `evals`, main-app `scripts`, `alembic`, `typings`) and prohibited library dependencies in rule 2, distinguishing isolated baseline adapters from P; flag path-based imports escaping the Lab.
2. Accept an optional `--diff-file <path>` argument that reads a `git diff --name-only` list from disk and reports any file touched outside `research-lab/`.
3. Accept only exceptions backed by the boundary's required approval evidence, declared in `research-lab/scripts/independence_allowlist.toml` (initially empty). An entry alone is not authorization. For RL-005 permit only the exact approved workflow path once the dedicated-file exception is approved; reject all other out-of-Lab diffs.
4. Exit 0 on success, non-zero on any violation, with human-readable messages indicating file and line.

## Out of scope
- CI wiring (deferred to `RL-005`).
- Enforcement against JavaScript, SQL, or other non-Python files (follow-up when those appear).

## Deliverables
- `research-lab/scripts/check_independence.py`
- `research-lab/scripts/independence_allowlist.toml` (empty, with a comment header).
- `research-lab/scripts/tests/test_check_independence.py` covering:
  - clean tree returns `OK`;
  - a dummy file with `import app.core.config` triggers exit code 1;
  - a dummy diff list containing `app/main.py` triggers exit code 1;
  - an unapproved allowlist entry does not suppress a violation;
  - an evidence-backed narrow exception accepts only its exact scope and rejects unrelated paths/imports.

## Acceptance criteria
- [ ] `cd research-lab && uv run python scripts/check_independence.py` on the current clean tree exits 0 and prints `OK`.
- [ ] Adding `import app.core.config` to any `research-lab/*.py` makes the script exit non-zero with a clear message.
- [ ] `cd research-lab && uv run pytest scripts/tests/test_check_independence.py` passes.
