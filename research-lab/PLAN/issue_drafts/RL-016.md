# [RL-016] Prepare paired D-23/D-24 and suite-release decisions

**Status:** Ready for paired preparation. **Labels:** `ready`, `decision`, `help wanted`, `paired`. **Milestone:** P1 Resolve open decisions.

## Goal
Prepare D-23 on T/D/G as primary H1/H3/H4 evidence and D-24 on release posture for T, D and G. Avoid unauthorized release of potentially sensitive material.

## Work and deliverables
Two contributors must coordinate: one suite/methodology perspective and one release-engineering perspective. The proposed Member 3 + Member 1 pairing is not an assignment. Create:

- `research-lab/PLAN/decisions/D-23.md`: cited evidence, alternatives and consequences for using T/D/G as primary evidence.
- `research-lab/PLAN/decisions/D-24.md`: proposed and authorized public/restricted/private posture for each suite, including dual-use considerations for G.
- Supported updates to the decision register and RL-131 release posture, only when actual decision evidence supports them.

## Acceptance
- Records cite relevant proposal passages, alternatives, rationale, consequences and actual decision status.
- Preparation is distinguished from supervisor disposition; approval is never inferred.
- Proposed and authorized release postures are distinguished. Do not publish suites without actual authorization.
- Both contributors participate; an independent reviewer distinct from both authors approves the work.
- Downstream task drafts/status match actual decisions; blocked generators remain gated.

## Prerequisites and dependencies
RL-001 is owner-confirmed Done; no task predecessor blocks preparation. RL-016 remains **blocking** for RL-022, RL-023 and RL-024. It is **not a prerequisite** for RL-020 or RL-021: RL-020's release-posture relationship is non-blocking; RL-021 has no RL-016 dependency. Both mirrors still require accepted RL-002 and RL-003. This task does not authorize release or start generators.

## Out of scope
Generating, running or releasing T/D/G; resolving D-15/D-16 or pilot thresholds; changing H1–H4, protocol or Frozen decisions.

## Claiming and review
Both contributors coordinate interest and participation before starting; a third, independent reviewer is required. Follow `PLAN/CONTRIBUTING.md` §3: read prerequisites, comment with the agreed claim/pairing, self-assign after coordination, and record actual participants in `PROJECT_STATUS.md` §3. Submit one PR containing both records; update status/register after independent review and acceptance. No member IDs are commitments.
