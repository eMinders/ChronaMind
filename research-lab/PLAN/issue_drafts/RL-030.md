# [RL-030] Evaluation harness skeleton, `MemorySystemAdapter`, and manifest writer

**Milestone:** `P3 Harness, baselines, judge, statistics`  
**Labels:** `enhancement`  
**Proposed Owner:** Member 5 (`R-APP`) · **Peer Reviewer:** Member 4 (`R-DB`)

## Objective & Why
Implement the core evaluation harness (`research-lab/evaluation/harness/`), the uniform `MemorySystemAdapter` protocol (`TECHNICAL_SPECIFICATION.md` §9.1), and the immutable run-output writer (`manifest.json`, `answers.jsonl`, `scores.jsonl`, `per_cluster.jsonl`) so all baselines (`B0`–`B4`), `P`, and ablations (`A1`–`A10`) execute under identical controlled conditions.

## Scope & Deliverables
- **In Scope:**
  - `MemorySystemAdapter` protocol (`reset_user`, `set_clock`, `ingest_turn`, `drain_queue`, `retrieve`, `answer`, `delete`).
  - Configuration loader pinning `model_id`, `embedding_model_id`, `judge_model_id`, `temperature = 0`, `seed`, and token budget `B_mem`.
  - Run output writer producing `evaluation/runs/<run_id>/<config_id>/<suite_id>/{manifest.json,answers.jsonl,scores.jsonl,per_cluster.jsonl}` (`TECHNICAL_SPECIFICATION.md` §9.2).
  - Guard refusing to execute test splits unless an explicit `--confirm-one-shot-test-run` flag and signed `RL-100` pilot freeze path are provided.
- **Out of Scope:**
  - Baselines `B0`–`B4` (`RL-031`), extraction replay cache (`RL-032`), LLM judge (`RL-033`), and full statistical module (`RL-034`).
- **Deliverables:**
  - `research-lab/evaluation/harness/`
  - `research-lab/evaluation/stats/__init__.py` (interface stub for `RL-034`)
  - Determinism smoke test in `research-lab/evaluation/harness/tests/`

## Acceptance Criteria
- [ ] Running a dummy adapter twice with the same seed produces byte-identical `answers.jsonl` and `scores.jsonl`.
- [ ] `manifest.json` records Git SHA, dirty-tree flag, dataset split SHA-256, model IDs, seed, timing (`P50`/`P95`), and token/cost counters.
- [ ] Attempting to run on a `test` split without the one-shot confirmation guard raises an immediate error.
