## Objective
Scaffold the evaluation harness: config layer, run manifest, scorer invocation, and the `runs/<ts>/<config>/<suite>/{answers.jsonl, scores.jsonl, per_cluster.jsonl, manifest.json}` layout.

- Run manifest: config hash, data hash, seed, timing, cost, env capture.
- Scorer invocation interface shared with `RL-025` adapters.
- Determinism: running any trivial baseline on a dummy suite produces byte-identical scores on repeat with the same seed.
