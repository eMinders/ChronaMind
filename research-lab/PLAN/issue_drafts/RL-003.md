# [RL-003] Author `research-lab/pyproject.toml`, `uv.lock`, and `.env.example`

**Milestone:** `P0 Repository, environment, and CI`  
**Labels:** `enhancement`  
**Proposed Owner:** Member 2 (`R-ENGINE`) · **Peer Reviewer:** Member 5 (`R-APP`)

## Objective & Why
Create the standalone Python package manifest (`pyproject.toml`), locked dependency graph (`uv.lock`), and environment variable template (`.env.example`) for `research-lab/` so all engine, harness, and test code runs reproducibly under Python 3.12+ without depending on the root `app/` environment.

## Scope & Deliverables
- **In Scope:**
  - Define core dependencies per `RL-013` and `PLAN/ARCHITECTURE.md` §3 (`psycopg[binary,pool]`, `pgvector`, `pydantic`, `numpy`, `scipy`, `pandas`, `tenacity`, `structlog`, `rich`) and dev dependencies (`pytest`, `pytest-asyncio`, `ruff`, `pyright`).
  - Define optional dependency groups for baselines (`mem0ai`, `graphiti-core` per `RL-031`) and the Phase P12 PDT demonstrator (`fastapi`, `uvicorn`).
  - Define `RL_*` prefixed environment variables in `research-lab/.env.example` (`RL_DATABASE_URL`, `RL_LLM_MODEL`, `RL_LLM_API_KEY`, `RL_EMBEDDING_MODEL`).
- **Out of Scope:**
  - Modifying the root `/pyproject.toml` or `/uv.lock` (`PLAN/INDEPENDENCE_BOUNDARY.md`).
- **Deliverables:**
  - `research-lab/pyproject.toml`
  - `research-lab/uv.lock`
  - `research-lab/.env.example`

## Acceptance Criteria
- [ ] Running `uv sync` inside `research-lab/` creates an isolated virtual environment cleanly.
- [ ] `uv run pytest --collect-only` exits `0`.
- [ ] Zero dependencies or path references point to the root `app/` package.
