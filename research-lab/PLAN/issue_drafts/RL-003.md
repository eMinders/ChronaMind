# [RL-003] Add Lab-scoped `.gitignore` and dependency manifest skeleton

**Labels:** `rl:kind/task`, `rl:phase/P0`, `rl:area/infrastructure`, `rl:status/blocked`, `rl:dep/blocking`, `rl:effort/S`, `rl:risk/low`
**Milestone:** `P0 Repository baseline`
**Phase final deliverable:** `D-P0`.
**Proposed owner:** Member 1 (R-INFRA).

## Objective
Give the Research Lab its own dependency manifest and ignore rules so that contributors can `uv sync` in `research-lab/` without touching the main app.

## Scope
- Add `research-lab/.gitignore` for:
  - Python caches (`__pycache__/`, `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`, `*.pyc`).
  - Virtualenvs (`.venv/`, `venv/`).
  - Per-run outputs (`evaluation/runs/**/*.jsonl` except `manifest.json` which is small and committed).
  - Benchmark raw data (`research/benchmarks/*/data/`).
  - OS cruft (`.DS_Store`, `Thumbs.db`).
- Add `research-lab/pyproject.toml` with:
  - `[project]` metadata: name `chronamind-research-lab`, version `0.1.0`, the supported compatible runtime selected by RL-013 (patch/environment pin captured per ARCHITECTURE.md §7).
  - Initial dev dependencies: `pytest`, `ruff`, `pyright`; add `pytest-asyncio` when async tests first appear, with independently verified constraints.
  - **No** runtime dependencies yet. (They are added by the task that first justifies them.)
  - Tool configuration for `ruff` (line length 120) and `pyright` (standard mode).

## Out of scope
- Any runtime library (`numpy`, `psycopg`, `pgvector-python`, `mem0ai`, `graphiti-core`, LLM SDKs). Those come with the task that first needs them.
- Dockerfile. Deferred — not required for this phase.
- `.env.example` — deferred until a task needs an environment variable.

## Deliverables
- `research-lab/.gitignore`
- `research-lab/pyproject.toml`
- `research-lab/uv.lock` with resolved transitive versions/hashes; frozen-lock install instructions.

## Acceptance criteria
- [ ] `cd research-lab && uv sync` creates a venv with only the declared dev dependencies.

- [ ] `cd research-lab && uv run ruff check .` exits 0.
- [ ] `cd research-lab && uv run pyright --help` runs (sanity).
- [ ] No file outside `research-lab/` modified.
