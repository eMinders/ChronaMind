# [RL-011] Author pre-registered pilot protocol (`evaluation/pilot_plan.md`)

**Milestone:** `P1 Resolve open decisions`  
**Labels:** `enhancement`  
**Proposed Owner:** Member 3 (`R-METHOD`) · **Peer Reviewer:** Member 1 (`R-LEAD`)

## Objective & Why
Author `research-lab/evaluation/pilot_plan.md` specifying the exact development-split measurement procedures and freeze formulas for all pilot-derived parameters (`D-09`–`D-14`, `D-21`, `D-22`) so the Phase P10 pilot (`RL-100`) freezes thresholds mechanically without post-hoc cherry-picking.

## Scope & Deliverables
- **In Scope (`PLAN/DECISIONS_REGISTER.md` §2.3):**
  - `D-09`: Retrieved memory token budget `B_mem` selection rule across `{512, 1024, 2048}`.
  - `D-10`: Primary and secondary `k` values for `Evidence Recall@k` on `LongMemEval_S` (`k ∈ {3, 5, 10}`).
  - `D-11`: Non-inferiority margin `δ_pres` for `H1` present-state `TAA(P) − TAA(A2)`.
  - `D-12`: Non-inferiority margin `δ_luar` for `H3` legitimate-update acceptance `LUAR(P) ≥ 1 − δ_luar`.
  - `D-13`: Scenario-level PDLR upper bound threshold `u*` (paired with `N_D` from `RL-014` `D-16` via `validation/cp_bounds.py`) and minimum `A8` (`P-nolineage`) positive-control detection share.
  - `D-14`: Precision-based scenario count sizing (`T`, `G`, `D`, `I`) and Suite `T` stratum ratio (`history-dependent` vs. `present-state`).
  - `D-21`: Operational and cost pass/fail rule for conditional Baseline `B4` (Graphiti).
  - `D-22`: Cost measurement rule deciding full `LongMemEval_S` (500 histories) vs. a seeded stratified subset.
- **Out of Scope:**
  - Running the pilot itself (owned by `RL-100`).
- **Deliverables:**
  - `research-lab/evaluation/pilot_plan.md`

## Acceptance Criteria
- [ ] Every parameter `D-09`–`D-14`, `D-21`, `D-22` has an explicit development-split measurement procedure and deterministic decision rule.
- [ ] Explicitly prohibits touching any test split (`splits/*.yaml`) during the pilot (`Graduation_Project_Proposal.md` §10.7).
- [ ] `python3 validation/mechanical_checks.py Graduation_Project_Proposal.md Methodology_and_Consistency_Checklist.md CHANGELOG.md` passes.
