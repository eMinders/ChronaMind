## Objective & Why
Provide a one-command isolated PostgreSQL container for `research-lab/` with `pgvector` and `btree_gist` pre-initialized, pinned to the exact version and image digest verified in `RL-012` (`D-25`).

## Scope & Deliverables
- **In Scope:**
  - `research-lab/docker-compose.yml` exposing PostgreSQL on host port `5433` (avoiding port `5432` used by the root app).
  - Initialization script `research-lab/src/custom_memory_engine/schema/init_extensions.sql` enabling `vector` (`pgvector`) and `btree_gist`.
  - Healthcheck ensuring readiness before running `validation/bitemporal_checks.sql` or `pytest`.
- **Out of Scope:**
  - Full 12-table DDL (owned by `RL-040`).
- **Deliverables:**
  - `research-lab/docker-compose.yml`
  - `research-lab/src/custom_memory_engine/schema/init_extensions.sql`

## Acceptance Criteria
- [ ] `docker compose -f research-lab/docker-compose.yml up -d` starts cleanly and passes healthcheck.
- [ ] Both `CREATE EXTENSION IF NOT EXISTS vector;` and `CREATE EXTENSION IF NOT EXISTS btree_gist;` succeed.
- [ ] Running `psql -v ON_ERROR_STOP=1 -f research-lab/validation/bitemporal_checks.sql` against the container passes all 43 assertions (`ALL ASSERTIONS PASSED`).
