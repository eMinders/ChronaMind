# [RL-006] Configure `ruff`, `pyright`, and cross-import guard

**Milestone:** `P0 Repository, environment, and CI`  
**Labels:** `enhancement`  
**Proposed Owner:** Member 5 (`R-APP`) · **Peer Reviewer:** Member 2 (`R-ENGINE`)

## Objective & Why
Configure static linting (`ruff`), type checking (`pyright` standard mode), and an automated import-boundary test inside `research-lab/` to enforce code quality and guarantee that no module in `research-lab/` ever imports from root `app/` or `evals/`.

## Scope & Deliverables
- **In Scope:**
  - `[tool.ruff]` and `[tool.pyright]` configuration in `research-lab/pyproject.toml`.
  - `research-lab/implementation/tests/test_independence_boundary.py` scanning all `.py` files in `research-lab/` to assert zero `from app` / `import app` / `from evals` / `import evals` statements (`PLAN/INDEPENDENCE_BOUNDARY.md` §3.1).
- **Out of Scope:**
  - Modifying root `.pre-commit-config.yaml` or root `pyproject.toml`.
- **Deliverables:**
  - Linter/typechecker configuration in `research-lab/pyproject.toml`
  - `research-lab/implementation/tests/test_independence_boundary.py`

## Acceptance Criteria
- [ ] `uv run ruff check .` and `uv run pyright` exit `0` inside `research-lab/`.
- [ ] `uv run pytest implementation/tests/test_independence_boundary.py` passes and fails on a synthetic `import app` fixture.
