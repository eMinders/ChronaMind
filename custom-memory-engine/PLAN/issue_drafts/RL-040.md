# [RL-040] Full 12-table PostgreSQL DDL (`Proposal §8`, `TECHNICAL_SPECIFICATION.md §3`)

**Milestone:** `P4 Schema and engine core`  
**Labels:** `enhancement`  
**Proposed Owner:** Member 4 (`R-DB`) · **Peer Reviewer:** Member 2 (`R-ENGINE`)

## Objective & Why
Author the complete 12-table PostgreSQL schema (`Graduation_Project_Proposal.md` §8 and `TECHNICAL_SPECIFICATION.md` §3) extending the proven reduced-schema design check (`validation/bitemporal_checks.sql`) to support all 10 database invariants.

## Scope & Deliverables
- **In Scope:**
  - All 12 canonical tables (`TECHNICAL_SPECIFICATION.md` §3.1): `APP_USER`, `SESSION`, `TURN`, `PREDICATE_SCHEMA`, `MEMORY_VERSION`, `MEMORY_EVIDENCE`, `MEMORY_DERIVATION`, `MEMORY_EMBEDDING`, `MEMORY_CONFLICT`, `AUDIT_EVENT`, `DELETION_REQUEST`, `JOB`.
  - **Invariant 1:** `DEFERRABLE INITIALLY DEFERRED` constraint trigger ensuring every committed `active`/`archived` row has `≥ 1` `MEMORY_EVIDENCE` row or `≥ 1` outgoing `MEMORY_DERIVATION` row (`TECHNICAL_SPECIFICATION.md` §4).
  - **Invariants 2 & 4:** `valid_wellformed`, `recorded_iff_believed`, `recorded_wellformed` `CHECK` constraints + `no_bitemporal_overlap` `EXCLUDE USING gist` constraint (`btree_gist`).
  - **Invariant 3:** Injectable `clock_now()` function and `guard_update()` trigger permitting post-insert updates only to `status`, `archival_branch`, and closing `upper(recorded_range)`.
  - **Invariant 7:** `user_id` columns and `ENABLE` / `FORCE ROW LEVEL SECURITY` scaffolding on all user-data tables.
  - **Invariant 9:** Unique constraints on `JOB.idempotency_key` and `(user_id, turn_id, extractor_version, candidate_fingerprint)`.
- **Out of Scope:**
  - Python migration runner (`RL-041`), transactional supersession/archival procedures (`RL-042`), and retrieval queries (`RL-043`).
- **Deliverables:**
  - `research-lab/src/custom_memory_engine/schema/001_full_schema.sql`
  - `research-lab/src/custom_memory_engine/schema/README.md` (mapping Invariants `1`–`10` to exact DDL constraints/triggers/procedures)

## Acceptance Criteria

- [ ] `src/custom_memory_engine/schema/README.md` documents the exact enforcement site for each of Invariants `1`–`10`.
