# [RL-023] Own Suite `D` (deletion and canary) generator

**Milestone:** `P2 Benchmarks and own suites`  
**Labels:** `enhancement`  
**Proposed Owner:** Member 3 (`R-METHOD`) · **Peer Reviewer:** Member 2 (`R-ENGINE`)

## Objective & Why
Build the deterministic script-first generator for Suite `D` (`Graduation_Project_Proposal.md` §§7.7, 10.2, 10.3) to evaluate `H4` (post-deletion leakage rate `PDLR` across all 7 in-boundary channels and positive-control sensitivity on `A8` `P-nolineage`).

## Scope & Deliverables
- **In Scope:**
  - Generate `N_D` independent scenarios (per `RL-014` `D-16`) containing fictional canary facts that cannot be guessed from parametric knowledge.
  - Cover all required lineage structures: (1) direct extracted memory, (2) fact consolidated into a semantic memory, (3) fact embedded in a multi-source summary, (4) fact superseded earlier (`R6` check that closed-belief versions are also erased), and (5) multi-turn re-learning control cases (scored separately per `Proposal` §10.2).
  - Generate direct and indirect probes across the 7 channels (`Proposal` §10.3) plus **never-stated control probes** to measure false-positive canary matches.
- **Out of Scope:**
  - Implementing the deletion procedure (`RL-070`) or running `H4` (`RL-105`).
- **Deliverables:**
  - `research-lab/research/benchmarks/own_D/{generator.py,MANIFEST.txt,README.md}`
  - Reproducibility unit tests.

## Acceptance Criteria
- [ ] Deterministic output for a fixed seed matching `N_D` from `RL-014` (`D-16`).
- [ ] Each scenario includes derived-memory canaries so `A8` (`P-nolineage`) leaks deterministically on Channel 4/5/6 while `P` removes them.
- [ ] Re-learning cases and never-stated control probes are explicitly tagged in scenario metadata so the scorer separates them from primary `H4` `PDLR`.
