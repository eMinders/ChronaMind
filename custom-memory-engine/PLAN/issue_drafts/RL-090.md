# [RL-090] `T1`–`T5` archival-precondition regression harness (`Invariant 10`, `Gate J6`)

**Milestone:** `P9 Testing matrix`  
**Labels:** `enhancement`  
**Proposed Owner:** Member 4 (`R-DB`) · **Peer Reviewer:** Member 2 (`R-ENGINE`)

## Objective & Why
Implement the five deterministic integration tests (`T1`–`T5`, `Graduation_Project_Proposal.md` §§7.5, 8 Invariant 10, `Methodology_and_Consistency_Checklist.md` §5, and `TECHNICAL_SPECIFICATION.md` §6) verifying that the V4 Archival Precondition (`(S) ∨ (C)`) prevents silent loss of both currently valid and historical current beliefs while maintaining deletion closure.

## Scope & Deliverables
- **In Scope (`TECHNICAL_SPECIFICATION.md` §6):**
  - **`T1`:** Reject archival (`VALIDATION_ERROR: archival_precondition_unmet`) of a currently-valid current belief (`status = 'active'`, `upper_inf(R)`, `ρ ∈ V`) when no `Active` derived replacement exists.
  - **`T2`:** Reject archival (`VALIDATION_ERROR: archival_precondition_unmet`) of a **historical current belief** (`status = 'active'`, `upper_inf(R)`, `upper(V) <= ρ`, e.g., `v1″` in `Proposal` §7.4) when no `Active` derived replacement exists, and confirm it remains returned by `historical_as_of`.
  - **`T3`:** Accept archival via branch `(S)` on a superseded version (`NOT upper_inf(R)`), recording `archival_branch = 'S'`, and verify it remains visible to `audit_as_of`.
  - **`T4`:** Accept archival via branch `(C)` when an `Active` derived replacement `r'` exists with `MEMORY_DERIVATION(derived_version_id = r', source_version_id = r)` and `V(r') @> V(r)`, recording `archival_branch = 'C'`, and verify `r'` answers `current_state` / `historical_as_of` queries.
  - **`T5`:** Execute `delete_memory(r.memory_key)` after `T4` and verify that a single transaction removes all versions of `r.memory_key` **and** removes (or re-derives without `r`) the derived replacement `r'` with zero leakage across all 7 channels.
- **Out of Scope:**
  - Modifying the core `archive_version` or `delete_memory` implementations (`RL-042`, `RL-070`), except to fix bugs uncovered by `T1`–`T5`.
- **Deliverables:**
  - `research-lab/tests/integration/archival/test_t1_to_t5.py`
  - `research-lab/tests/integration/archival/README.md`
  - Updated `TRACEABILITY_MATRIX.md` §2 (Invariant 10) and §5 (`Gate J6`).
